# 컬링 / LOD 최적화 기록 (GameScene)

브랜치 `perf/culling-lod`. 오클루전 컬링, LOD Group, Mesh LOD 적용 전후를 같은 조건에서 측정한 결과.

## 측정 방법

- 도구: `Tools/PerfBench.cs` (Play 모드에서 `run_script`로 실행, 프로젝트 코드 아님)
- 고정 시점 5곳. 입력/AI/카메라 스크립트를 끄고 플레이어·카메라 위치를 고정, 좀비 10마리를 같은 자리에 배치
  - V1_Spawn: 스폰 지점 1인칭, 북쪽
  - V2_LongRoad: 동쪽 도로 끝에서 서쪽으로 긴 시야
  - V3_TankOccl: 오일탱크 바로 앞 (탱크 뒤가 가려지는 시점)
  - V4_Quarter: 쿼터뷰(플레이어 약 12m 거리)
  - V5_Zombies: 남쪽 도로, 좀비 10마리(5~44m)
- 시점마다 30프레임 안정화 후 90프레임 중앙값. 프로파일러 카운터(Triangles/Batches/SetPass/Shadow Casters 등)는 **프레임 전체**(메인 카메라 + 그림자 캐스케이드 4개 + 뎁스 + 미니맵 카메라) 기준
- `all` = 전체, `excl_tripo` = Sword/Pistol/DeadPool 렌더러를 끄고 측정
  - 게임 기본 상태(총 모드)에서는 `SwordHolder`가 비활성이라 Sword는 원래 그려지지 않음. 즉 차이는 Pistol + DeadPool
- Game View 1752x467 (모든 단계 동일)

## 프레임 시간

단계별 측정은 Play 세션이 매번 달라 에디터 프레임 시간이 세션마다 ±1ms 가까이 흔들렸다(최종 측정이 기준보다 오히려 느리게 나옴). 그래서 `Tools/AbFrameTime.cs`로 **한 세션 안에서** "최적화 끔(오클루전 끔 + LODGroup 끔 + Mesh LOD 0 강제 + Far 1000)"과 "최적화 켬"을 AB/BA/AB 순서로 번갈아 측정했다. "끔" 상태의 Triangles가 기준 측정과 거의 같아(V1 1.422M vs 1.426M) 기준 상태가 제대로 재현됨을 확인했다.

| 시점 | CPU Main (ms) | CPU Render (ms) | GPU (ms) |
|---|---|---|---|
| V1_Spawn | 3.73 → 3.84 (+3%) | 2.82 → 2.83 | 3.48 → 3.27 (-6%) |
| V2_LongRoad | 4.35 → 4.25 (-2%) | 3.07 → 2.95 | 3.53 → 3.52 (0%) |
| V3_TankOccl | 4.18 → 3.65 (-13%) | 3.00 → 2.98 | 3.63 → 3.48 (-4%) |
| V4_Quarter | 4.07 → 4.00 (-2%) | 3.02 → 2.97 | 3.52 → 3.35 (-5%) |

에디터 측정이라 절대값은 참고용. 삼각형이 크게 줄어도 프레임 시간 개선이 작은 것은 이 씬이 현재 해상도에서 정점 처리 병목이 아니기 때문. 실제 수치는 Development Build + Profiler로 확인하는 것이 정확하다.

## Mesh LOD: 가까이 있을 때 효과 확인 (`Tools/MeshLodProbe.cs`)

Sword/Pistol/DeadPool만 "자동 선택" vs "LOD0 강제"로 바꿔 같은 프레임의 Triangles 비교.

| 조건 | 자동 | LOD0 강제 | 차이 |
|---|---:|---:|---|
| V1 전체 | 752,045 | 1,411,049 | -47% |
| V1 미니맵 카메라 끔 | 641,954 | 641,954 | **0** |
| V1 미니맵 끔 + Tripo 그림자 끔 | 257,298 | 257,298 | **0** |
| 근접 Sword 0.6m | 994,243 | 994,243 | **0** |
| 근접 Pistol 0.4m | 696,466 | 696,466 | **0** |
| 근접 DeadPool 2m | 467,900 | 711,562 | -34% |
| 원거리 DeadPool 15m | 48,688 | 232,617 | -79% |

- 1인칭 메인 카메라와 그 그림자에서는 Mesh LOD 효과가 **0**. 무기를 바로 앞에서 볼 때도 0 → "가까이 있으면 LOD0이 선택된다"는 예상과 일치
- V1에서 줄어든 47%는 전부 **미니맵 카메라**(플레이어 30m 위 직교 카메라)에서 플레이어 모델이 작게 보여 낮은 LOD가 선택된 덕분
- DeadPool은 2m에서도 일부 감소(화면 대비 메시가 너무 촘촘함), 쿼터뷰(약 12m)에서는 -84%

| 단계 | 내용 |

## 시각 검증

기준 스크린샷과 각 단계 스크린샷을 HUD 영역을 빼고 픽셀 비교: V1~V4는 0.03% 이하 차이. V5는 0.4~1.2%로, 차이 마스크를 보면 좀비 실루엣(대기 애니메이션 위상 차이)뿐이었다. 잘못 가려진 물체는 발견되지 않았다.

LOD 전환은 정지 스크린샷으로만 확인했다(움직이며 보는 팝핑 테스트는 하지 않음). 좀비 Culled 기준(약 65m, 1080p에서 키 약 27px)은 먼 직선 도로에서 눈에 띌 수 있으니 플레이해 보고 필요하면 0.05 → 0.02(약 160m)로 낮출 것.
